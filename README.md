# Kaiyue Chen’s Homepage

Personal academic homepage for Kaiyue Chen, an undergraduate in Mechatronics
and Robotic Systems at Xi'an Jiaotong-Liverpool University.

This is a build-free static site. The page lives in `index.html`, with styles
in `stylesheet.css` and local assets under `assets/` and `images/`.

For a local preview:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

Content was migrated from the previous homepage in `Kaiyuechen.github.io`.
The selected publication, 3WD-VLA, is accepted at EAI CollaborateCom 2026.
The CV button opens `assets/files/CV.pdf` in a new tab.

Canonical and social-sharing URLs use the GitHub Pages user-site address:
`https://kaiyuechen24.github.io/`.
Update these URLs in `index.html` if the repository name or custom domain
changes.

The visual template is adapted from Jiayi Zhang's academic homepage.
The original MIT license is retained in `LICENSE`.
